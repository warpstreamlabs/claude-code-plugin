# Security Policy

## Supported Versions

The latest release of the WarpStream plugin for Claude receives security fixes. Update the plugin from the `/plugin` menu in Claude Code to get them.

## Reporting a Vulnerability

If you have found or suspect a vulnerability in this plugin (its skills, commands, bundled scripts or MCP configuration), please report it to security@warpstreamlabs.com rather than opening a public issue.

Please include what you found, how to reproduce it, and the plugin version (from `.claude-plugin/plugin.json`).

The same address handles vulnerabilities in WarpStream itself.

Please note, we do not operate a bug bounty program. However, we deeply appreciate any contributions that guide us towards building a better and safer project.
